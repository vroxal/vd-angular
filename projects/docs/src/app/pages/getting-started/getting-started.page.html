For designers

Designers can access the official Vroxal Design System on Figma. This file includes foundations, components, and usage guidelines that stay in sync with the development packages.

  • Design tokens (colors, typography, spacing)
  • Ready-to-use components
  • Usage guidelines and best practices

Use the Figma file as the single source of truth while designing new features or iterating on existing ones.
